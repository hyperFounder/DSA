# LeetCode Practice Questions: DFS, BFS, & Trees

A curated collection of LeetCode problems covering Depth-First Search (DFS), Breadth-First Search (BFS), Binary Trees, and Graphs, ordered by difficulty.

---

## Easy

These problems focus on basic recursive traversal (DFS) and level-by-level queue processing (BFS).

* **104. Maximum Depth of Binary Tree**
  * **Concepts:** DFS (Recursion), Tree Height
* **226. Invert Binary Tree**
  * **Concepts:** DFS, Tree Manipulation
* **100. Same Tree**
  * **Concepts:** DFS, Simultaneous Tree Traversal
* **112. Path Sum**
  * **Concepts:** DFS Backtracking
* **637. Average of Levels in Binary Tree**
  * **Concepts:** BFS (Queue)

---

## Medium

These problems introduce graph traversals on 2D grids, topological sorting, and structural tree manipulations.

* **102. Binary Tree Level Order Traversal**
  * **Concepts:** BFS, Level-by-Level List Construction
* **200. Number of Islands**
  * **Concepts:** 2D Grid Traversal, DFS / BFS, Connected Components
* **236. Lowest Common Ancestor of a Binary Tree**
  * **Concepts:** DFS Recursion, Node Bubble-Up
* **105. Construct Binary Tree from Preorder and Inorder Traversal**
  * **Concepts:** Tree Reconstruction, Divide & Conquer
* **133. Clone Graph**
  * **Concepts:** Graph Traversal, HashMap Hash Table, DFS / BFS
* **207. Course Schedule**
  * **Concepts:** Directed Graph, Cycle Detection, Topological Sort (Kahn's BFS / DFS)

---

## Hard

These problems require combining traversal with dynamic programming, memoization, bidirectional search, or complex state serialization.

* **124. Binary Tree Maximum Path Sum**
  * **Concepts:** Advanced Tree DFS, Global State Tracking
* **297. Serialize and Deserialize Binary Tree**
  * **Concepts:** Tree Representation, Preorder Traversal / BFS Encoding
* **127. Word Ladder**
  * **Concepts:** Shortest Path BFS, State Transition Graphs
* **329. Longest Increasing Path in a Matrix**
  * **Concepts:** Grid DFS, Memoization / Dynamic Programming
* **827. Making A Large Island**
  * **Concepts:** Multi-Pass Grid DFS, Component Sizing, Union-Find
