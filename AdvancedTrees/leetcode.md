# LeetCode Practice Questions: DFS, BFS, & Trees

A curated collection of LeetCode problems covering Depth-First Search (DFS), Breadth-First Search (BFS), Binary Trees, and Graphs, ordered by difficulty.

---

## Easy

These problems focus on basic recursive traversal (DFS) and level-by-level queue processing (BFS).

* **[104. Maximum Depth of Binary Tree](https://leetcode.com/problems/maximum-depth-of-binary-tree/)**
  * **Concepts:** DFS (Recursion), Tree Height
* **[226. Invert Binary Tree](https://leetcode.com/problems/invert-binary-tree/)**
  * **Concepts:** DFS, Tree Manipulation
* **[100. Same Tree](https://leetcode.com/problems/same-tree/)**
  * **Concepts:** DFS, Simultaneous Tree Traversal
* **[112. Path Sum](https://leetcode.com/problems/path-sum/)**
  * **Concepts:** DFS Backtracking
* **[637. Average of Levels in Binary Tree](https://leetcode.com/problems/average-of-levels-in-binary-tree/)**
  * **Concepts:** BFS (Queue)

---

## Medium

These problems introduce graph traversals on 2D grids, topological sorting, and structural tree manipulations.

* **[102. Binary Tree Level Order Traversal](https://leetcode.com/problems/binary-tree-level-order-traversal/)**
  * **Concepts:** BFS, Level-by-Level List Construction
* **[200. Number of Islands](https://leetcode.com/problems/number-of-islands/)**
  * **Concepts:** 2D Grid Traversal, DFS / BFS, Connected Components
* **[236. Lowest Common Ancestor of a Binary Tree](https://leetcode.com/problems/lowest-common-ancestor-of-a-binary-tree/)**
  * **Concepts:** DFS Recursion, Node Bubble-Up
* **[105. Construct Binary Tree from Preorder and Inorder Traversal](https://leetcode.com/problems/construct-binary-tree-from-preorder-and-inorder-traversal/)**
  * **Concepts:** Tree Reconstruction, Divide & Conquer
* **[133. Clone Graph](https://leetcode.com/problems/clone-graph/)**
  * **Concepts:** Graph Traversal, HashMap Hash Table, DFS / BFS
* **[207. Course Schedule](https://leetcode.com/problems/course-schedule/)**
  * **Concepts:** Directed Graph, Cycle Detection, Topological Sort (Kahn's BFS / DFS)

---

## Hard

These problems require combining traversal with dynamic programming, memoization, bidirectional search, or complex state serialization.

* **[124. Binary Tree Maximum Path Sum](https://leetcode.com/problems/binary-tree-maximum-path-sum/)**
  * **Concepts:** Advanced Tree DFS, Global State Tracking
* **[297. Serialize and Deserialize Binary Tree](https://leetcode.com/problems/serialize-and-deserialize-binary-tree/)**
  * **Concepts:** Tree Representation, Preorder Traversal / BFS Encoding
* **[127. Word Ladder](https://leetcode.com/problems/word-ladder/)**
  * **Concepts:** Shortest Path BFS, State Transition Graphs
* **[329. Longest Increasing Path in a Matrix](https://leetcode.com/problems/longest-increasing-path-in-a-matrix/)**
  * **Concepts:** Grid DFS, Memoization / Dynamic Programming
* **[827. Making A Large Island](https://leetcode.com/problems/making-a-large-island/)**
  * **Concepts:** Multi-Pass Grid DFS, Component Sizing, Union-Find
